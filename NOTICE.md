# Происхождение материалов

В репозиторий включены два скилла, предоставленные владельцем: coursework-word и coursework-diagrams, а также их исходные методические материалы, шаблоны и инструменты.

Методички, учебные примеры, документы колледжа, шрифты Liberation и локальный просмотрщик Draw.io являются отдельными материалами. Их авторство и условия использования не изменяются размещением в этом репозитории. Лицензия на весь набор не объявляется единой. Для шрифтов включён отдельный текст SIL Open Font License из официального тега Liberation Fonts 2.1.5. Для просмотрщика приложен текст Apache License 2.0; исходные встроенные уведомления компонентов сохранены. Версия ранее поставленного просмотрщика не установлена.

Рабочая курсовая, личный профиль студента, протоколы чата, кэш Python и временные файлы сборки не входят в поставку.
