# Скиллы для курсовых проектов

Два переносимых скилла с методичками, версиями и проверкой обновлений.

| Скилл | Версия | Назначение |
|---|---|---|
| coursework-word | 1.0.0 | Пояснительная записка Word по методичкам колледжа |
| coursework-diagrams | 1.0.0 | IDEF0, DFD и UML в Draw.io |

## Установка

Откройте [Releases](https://github.com/NXR333/codex-skills/releases) и скачайте ZIP нужного скилла. Распакуйте содержащуюся в нём папку `coursework-word` или `coursework-diagrams` в ваш каталог навыков (для этой поставки — `~/.codex/skills/`). Перед заменой уже установленной папки сохраните её копию. Если скилл не появился, откройте новый чат или перезапустите приложение.

Для установки с проверкой контрольных сумм скачайте или клонируйте этот репозиторий и выполните из его папки (Python 3.10 или новее, дополнительные пакеты не нужны):

```console
python scripts/skills.py install coursework-word
python scripts/skills.py install coursework-diagrams
```

Уже существующие папки команда install не перезаписывает. Для другого расположения навыков используйте `--root "путь/к/skills"`; также учитывается CODEX_HOME.

## Проверка актуальности

```console
python scripts/skills.py check
```

Либо из любой установленной папки скилла:

```console
python "путь/к/coursework-word/scripts/check_version.py"
```

При первом применении в новом чате инструкция скилла предлагает выполнить эту проверку. Это инструкция агенту, а не фоновый процесс или встроенный механизм приложения. Для работы необходимы доступный Python и сеть; без них основная задача продолжается, а актуальность не считается подтверждённой.

Проверка различает актуальную версию, доступное обновление, локальные правки и недоступность каталога. Она ничего не устанавливает и не отправляет локальные файлы: скачивается только публичный каталог. Хеши позволяют заметить изменения даже при неизменившемся номере версии.

Версия поставки и актуальность содержания — разные вещи. Новые редакции методичек нужно добавлять и проверять отдельно; программа не может подтвердить правильность правил оформления или действующую редакцию ГОСТ по одному номеру скилла.

## Обновление

```console
python scripts/skills.py update coursework-word
python scripts/skills.py update coursework-diagrams
```

Обновляется только более старая неизменённая версия. Сначала проверяются ZIP, манифест и файлы по SHA-256, затем старая папка переносится в `skill-backups` рядом с каталогом навыков. При локальных правках или отсутствии манифеста обновление останавливается. Копия сохраняется для восстановления; при ошибке замены прежняя папка возвращается автоматически. Для ручного отката перенесите текущую папку в отдельное место и верните соответствующую копию из `skill-backups`.

Для проверки без сети: `--catalog catalog.json`. Для установки проверяемого локального архива используйте `--catalog catalog.json --package "путь/к/архиву.zip"`.

## Как выпускать изменения

Версии каждого скилла независимы: исправление — 1.0.1, новая совместимая возможность — 1.1.0, несовместимые изменения — 2.0.0. Начальная версия 1.0.0 фиксирует текущее состояние, не имитируя историю до создания репозитория. Номер всего комплекта хранится в VERSION.

1. Изменить скилл в `skills/` и его CHANGELOG.md. Для изменения общего проверяющего скрипта обновить также его копии внутри обоих скиллов.
2. Зафиксировать новый номер и контрольные суммы: `python scripts/skills.py stamp coursework-word 1.0.1`. Не редактировать files в version.json вручную.
3. Повысить версию комплекта в VERSION, обновить RELEASE_NOTES.md.
4. Выполнить `python scripts/skills.py build`, `python scripts/skills.py validate` и `python -m unittest discover -s tests -v`. Добавить изменённый catalog.json в коммит.
5. После проверки изменений отправить коммит и тег `v<версия комплекта>` в GitHub. Workflow Release skills проверит пакет и опубликует ZIP, каталог и SHA256SUMS.txt в GitHub Release.

На push и pull request запускаются тесты, проверка ссылок, контрольных сумм и увеличения версии изменённого скилла. Проверки программные; они не заменяют содержательную и визуальную проверку скилла на реальной задаче.

Материалы и их происхождение описаны в [NOTICE.md](NOTICE.md).
