# Данные текущего проекта

Скилл передаётся без персонального профиля автора. Сведения брать из текущих файлов и сообщений пользователя; не переносить ФИО, группу, тему, руководителя и требования другого проекта из образцов.

Для титульного листа нужны ФИО студента, актуальная группа, тема, руководитель и год выполнения. По встроенным материалам учреждение — Рязанский станкостроительный колледж РГРТУ, специальность — 09.02.07 «Информационные системы и программирование», МДК.05.02 — «Разработка кода информационных систем»; сверить их с текущим заданием.

Для содержательных разделов установить предметную область, реальные процессы As-Is, роли, функции, сущности и связи, выбранные технологии и результаты испытаний. Не сочинять неизвестное; существенное недостающее уточнять, продолжая независимую работу.

Регистрацию, авторизацию, число таблиц, роли, размеры окна и типы данных считать требованиями только при наличии в текущем задании или подтверждённой реализации. Не добавлять искусственные сущности ради числа.

Не закреплять .NET, SQL Server, WPF, EF Core и версии ПО по учебному примеру. Читать файлы текущего проекта.
