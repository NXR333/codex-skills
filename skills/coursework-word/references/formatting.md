# Оформление по методичке МДК.05.02, Рязань, 2026

## Страница и текст — п. 3.1

| Параметр | Требование |
|---|---|
| Формат | А4, односторонняя печать |
| Поля | Слева 30 мм, справа 15 мм, сверху и снизу не менее 20 мм |
| Шрифт | Liberation Serif, чёрный, не менее 12 пт |
| Интервал | 1,5 |
| Основной текст | По ширине; абзацный отступ 1,25 см |
| Общий объём | 25–45 страниц; учитывать расхождение с объёмами разделов |

Если размер не согласован, выбрать 12 пт; верхнее и нижнее поля — 20 мм. Это рабочие значения внутри разрешённых границ, а не единственные допустимые. Не заменять Liberation Serif на Times New Roman молча. Если гарнитура недоступна, установить разрешённым способом или назвать ограничение.

Применять полужирное начертание к заголовкам разделов, подразделов и структурных элементов. Не вводить массовое выделение основного текста. Исключения для специальных обозначений и терминов рассматривать по п. 3.1, не распространять на весь текст.

## Заголовки и страницы — пп. 3.1–3.3

- Разделы и подразделы: с абзацного отступа, после номера, с прописной буквы, полужирные, без подчёркивания и точки в конце.
- Номера: `1 Заголовок`, `1.1 Заголовок`, `1.1.1 Заголовок`, без завершающей точки.
- Введение, заключение и список источников не нумеровать.
- СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ, СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ, ПРИЛОЖЕНИЕ — прописными по центру.
- Каждый раздел и структурный элемент начинать с новой страницы. Не разрывать каждый подраздел без причины.
- Страницы считать с титульника до последнего листа приложений. Номер снизу по центру без точки, на титульнике скрыт.
- Использовать поле PAGE и особый колонтитул первой страницы; сохранять непрерывную нумерацию при смене разделов Word.
- Использовать настоящие стили заголовков с уровнями; ненумеруемые элементы включать в оглавление отдельно, само содержание в себя не включать.

## Оглавление — п. 3.2

Включать введение, именованные разделы, подразделы и необходимые пункты, заключение, источники, приложения. Текст должен совпадать с заголовками. Каждая запись — отдельный абзац слева, номер страницы справа, соединён отточием. Подразделы смещать на два знака относительно разделов, пункты — на четыре; произвольные сантиметры не выдавать за цитату методички.

Создавать поле TOC и табуляцию, а не ручные точки и номера. Обновить после окончательной пагинации и сверить реальные страницы. Если движок не обновляет поля, не утверждать, что номера проверены.

## Перечисления — п. 3.3

Использовать тире; для ссылки на элемент — строчные русские буквы со скобкой, кроме е, з, й, о, ч, ъ, ы, ь. При конкретном числе элементов допустимы цифры со скобкой. Располагать в столбик с абзацного отступа. Простые элементы разделять запятыми, сложные — точками с запятой.

## Рисунки — п. 3.4

После первого упоминания или на следующей странице, со ссылкой в тексте. Подпись под рисунком и пояснениями, по центру, без точки: `Рисунок 1 – Схема интерфейса`. Допустим вариант внутри раздела (`Рисунок 3.1`). Выбрать один вариант, сохранить согласованный в исходном документе.

В приложениях отдельная нумерация: `Рисунок А.1`. Ссылка: «в соответствии с рисунком 2». Проверять читаемость при масштабировании и соответствие обозначений тексту.

## Таблицы — п. 3.5

Предпочтение пользователя: использовать обычные редактируемые таблицы Word без заливки, цветных шапок, чередования цветов строк и декоративных стилей. Текст — чёрный; границы — сплошные чёрные одинаковой толщины (рабочее значение 0,5 пт), включая внутреннюю сетку. Шапку не выделять отдельной заливкой или полужирным шрифтом. Это предпочтение оформления данного профиля, а не цитата из методички; текущее явное указание пользователя имеет приоритет. Не распространять сетку на невидимые служебные таблицы титульника и бланков.

При сборке из чужих документов убирать у содержательных таблиц унаследованные заливки и условные стили, проверять границы каждой ячейки, чтобы не оставались пропуски сетки. Отсутствие заливки задавать без принудительного белого заполнения. Проверять результат в светлом рендере: тёмная тема Word сама по себе не означает наличие заливки в документе. Сохранять предусмотренные методичкой исключения для границ переносимой таблицы.

После первого упоминания или на следующей странице, со ссылкой в тексте. Подпись сверху слева без абзацного отступа: `Таблица 1 – Перечень элементов`, без точки. Многострочная подпись — одинарный интервал.

Нумерация сквозная либо внутри раздела, последовательно. В приложениях — `Таблица В.1`. Над следующей частью переносимой таблицы — `Продолжение таблицы 1`, без повторения названия. У первой переносимой части по методичке не проводить нижнюю ограничивающую черту. Повторять головку для читаемости, проверять перенос визуально.

Заголовки граф — с прописной буквы, в единственном числе, без завершающих знаков. Подзаголовки — со строчной, если продолжают заголовок. Не делить головку диагоналями. Отсутствующие данные обозначать прочерком. Числа не заменять кавычками; сохранять одинаковую точность столбца. Допустим уменьшенный читаемый шрифт таблицы.

## Источники — п. 3.6

Не менее трёх источников; возраст и порядок см. sources.md. Включать источники, на которые есть ссылки в записке. Номера арабские без точки, с абзацного отступа. Образцы описания брать из методички. Не копировать даты обращения из примеров: указывать фактическую дату проверки.

## Приложения — п. 3.7

В порядке появления ссылок, каждое с новой страницы. По центру `ПРИЛОЖЕНИЕ А`, следующей строкой симметричный заголовок с прописной буквы. Буквы русского алфавита, кроме Ё, З, Й, О, Ч, Ь, Ы, Ъ. Единственное приложение также А. Общая нумерация страниц; номера элементов — с буквой приложения.
