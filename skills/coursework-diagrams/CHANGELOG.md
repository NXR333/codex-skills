# История изменений coursework-diagrams

## 1.0.0 — 12.11.2026

Первая зафиксированная версия текущего скилла. Добавлены манифест с контрольными суммами и проверка обновлений. Более ранним изменениям номера версий задним числом не присваиваются.

Сохранены методички по нотациям, редактируемый эталон Draw.io, локальный просмотрщик и инструменты генерации, рендера и проверки. Служебный кэш Python исключён из поставки.
